Module 01 · Portfolio & programs

Your entire portfolio, readable in one second.

No more Friday-night manual consolidations: every project lives in a rich tile, every program aggregates its projects automatically, and the cross-portfolio roadmap draws itself.

01.1

Project tiles that tell the whole story

Each tile concentrates the essentials: time progress, budget consumption, upcoming milestones, open risks and RAG status. Switch to a dense list view whenever you prefer a table — your choice is remembered.

  • Progress rings — schedule progress and budget consumption side by side, without opening the record.
  • Automatic RAG status — computed on budget, schedule and risks; the tile header turns green, amber or red.
  • Filters & search — by program, status, RAG, project manager; tiles / list toggle remembered per user.
  • Direct actions — open, edit, export from the tile, no intermediate navigation.
01.2

Programs that aggregate themselves

A program in MARCEL is not a folder: it is a living view that consolidates budgets, progress, risks and milestones from its projects. The program's next two milestones show directly on its tile.

  • Consolidated RAG — the program's status reflects the worst of its projects, with the detailed breakdown.
  • Program budget — envelopes, consumed and EAC aggregated automatically from projects.
  • Upcoming milestones on the tile — the program's next 2 milestones, in red when late.
  • Tabbed program record — Overview, Projects and all aggregated milestones in a single record.
01.3

Cross-portfolio roadmap & unique coding

The consolidated roadmap aligns all projects on a single timeline — milestones, dependencies and delays visible at a glance. And each project carries a unique, locked code (P01-001), generated per program, that follows it into every export.

  • Multi-project timeline — frozen scope vs actual: schedule drifts stand out in red.
  • Automatic coding — configurable prefixes per program, locked codes, server-side duplicate prevention.
  • Global search Ctrl + K — type a code or a name: projects, milestones, risks and decisions grouped by type.
